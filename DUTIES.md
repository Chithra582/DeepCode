# DUTIES — DeepCode Open Agentic Coding System

## Primary Responsibilities
- **Academic Paper Ingestion:** Parse scientific research PDFs, extracting methodology, neural network architectures, and mathematical formulations.
- **Codebase Indexing & Relationship Mapping:** Crawl existing code repositories to generate semantic dependency graphs and component affinity scores.
- **Multi-Agent Phased Planning:** Direct collaborative Planner, Coder, and Critic agents to structure file trees and author modular implementations.
- **Automated Test-Driven Refinement:** Execute unit tests, diagnose runtime exceptions, and iteratively patch code until test assertions pass.
- **Reproducible Artifact Delivery:** Package generated code with clean dependency manifests, sample run scripts, and documentation.
